# Real-Time Lens Flare Removal

Приложение для удаления бликов с объектива в реальном времени на Android.

## Установка

1. Клонируйте репозиторий:
   ```
   git clone https://github.com/yourusername/Real-Time-Lens-Flare-Removal.git
   ```

2. Откройте проект в Android Studio:
   - Запустите Android Studio
   - Выберите "Open an existing project"
   - Найдите и выберите папку с проектом

3. Настройка проекта:
   - Дождитесь завершения синхронизации Gradle
   - Убедитесь, что у вас установлен Android SDK (API 21 или выше)
   - Проверьте, что в `local.properties` указан правильный путь к SDK

4. Запуск приложения:
   - Подключите Android-устройство через USB или запустите эмулятор
   - Нажмите кнопку "Run" (зеленый треугольник) в Android Studio
   - Выберите устройство для запуска
   - Дождитесь установки и запуска приложения

## Требования

- Android Studio 4.0 или выше
- Android SDK API 21+
- Устройство с Android 5.0 или выше
- Камера на устройстве

## Возможные проблемы

1. Если возникают ошибки при синхронизации Gradle:
   - Проверьте подключение к интернету
   - Очистите кэш Gradle (File -> Invalidate Caches / Restart)
   - Обновите Gradle до последней версии

2. Если приложение не запускается:
   - Проверьте, что устройство подключено и отладка по USB включена
   - Убедитесь, что на устройстве установлены все необходимые драйверы
   - Проверьте логи в Android Studio для выявления ошибок
